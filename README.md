# 💬 ChatSphere – Real-Time Chat Application

## 🚀 Overview

**ChatSphere** is a real-time chat application built using the **MERN stack** with **Socket.IO** for instant messaging.

It allows users to sign up, log in and chat with other users in real time through a modern, responsive UI.

This project is being developed step-by-step using scalable architecture, authentication and real-time communication best practices.

---

## ✨ Features (Current MVP)

- 🔐 User Authentication (Signup / Login / Logout)
- 🛡️ JWT-based authentication system
- 💬 Real-time messaging with Socket.IO
- 🟢 Online/offline user status
- 👥 User list sidebar
- 🗄️ MongoDB database integration
- ⚡ REST API with Express.js
- 🎨 Responsive UI with React + Tailwind CSS

---

## 🧱 Tech Stack
